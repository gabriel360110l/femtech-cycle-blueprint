# Backup Strategy

## Default
- No account required
- All data stays on the device (encrypted local database)
- App works fully offline

## Optional backup
Users can choose to enable:
- Encrypted backup to iCloud or Google Drive
- Or an optional account with end-to-end encryption
- Or manual export (JSON/CSV/PDF) that they store themselves

## Principles
- Backup is never mandatory
- User stays in control
- Clear explanation: "Your data stays yours. Backup is optional."
- Easy full export + delete
