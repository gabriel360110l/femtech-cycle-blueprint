# Mode Separation: Cycle vs Pregnancy

Cycle mode and Pregnancy mode must feel like two different experiences.

## Rules
- Different home screens
- Different navigation and tabs
- Different tone and content
- No pregnancy/baby content while in Cycle mode
- No cycle/fertility predictions while in Pregnancy mode
- Switching modes is explicit (user chooses) and reversible
- All historical data stays available, but the UI changes completely

## Why
Mixing them creates confusion and can feel insensitive (especially after loss or when someone is not trying to conceive).
