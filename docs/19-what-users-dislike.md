# What Users Often Dislike (and how we avoid it)

| Common complaint              | How this app handles it                  |
|-------------------------------|------------------------------------------|
| Too many questions            | Short onboarding, fast daily logging     |
| Forced account                | No account required                      |
| Too pink / childish           | Terracotta + cream, calm tone            |
| Cycle + pregnancy mixed       | Strictly separate modes and screens      |
| Black-box predictions         | Short explanation of how it works        |
| Hard to export data           | One-tap PDF/CSV export                   |
| Privacy concerns              | Local-first by default                   |
