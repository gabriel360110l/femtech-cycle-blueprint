# Practical Logging Guide — What Users Should Be Able to Record

Detailed list of everything that is useful to log. Grouped so it can later become screens or forms.

## Daily essentials (always visible)
- Bleeding (none / spotting / light / medium / heavy)
- Pain severity (0–10) + main location
- Mood (simple tags or scale)
- Energy level
- Notes (free text)

## Fertility biomarkers (optional but powerful)
- Basal body temperature + time + disturbed flag
- Cervical mucus (dry / sticky / creamy / egg-white / watery)
- Cervical position (optional advanced)
- LH test result (negative / positive / peak)
- Pregnancy test result

## Pain & pathology details (Diagnostic mode)
- Multiple pain locations (lower abdomen, back, left/right ovary, rectum, bladder, legs, shoulder)
- Pain during sex (deep or superficial)
- Pain with bowel movement or urination
- Clot size
- Soaking through protection speed
- Endo-belly / bloating
- Painkillers taken and whether they helped

## Lifestyle & other useful logs
- Sleep quality / hours
- Stress level
- Exercise
- Alcohol
- Medication / supplements (especially folic acid, iron, vitamin D, progesterone, trigger shots)
- Sexual activity (protected / unprotected) — useful for TTC mode

## Cycle-level information
- Period start and end dates
- Known conditions (endo, PCOS, etc.)
- Current mode (Cycle, TTC, Pregnancy, Loss Recovery, etc.)
- Contraception type

## Why each item matters
- Bleeding + clots → heavy bleeding / fibroids / adenomyosis patterns
- Pain location + timing → endometriosis vs other causes
- BBT + mucus → reliable ovulation confirmation
- Mood only in luteal phase → PMDD pattern
- Medication flags → correct interpretation of tests (e.g. Ovitrelle)

Make logging fast. Most days the user should be able to log the essentials in under 15 seconds. Advanced fields can be behind an “add more” button.
